# Family Tree Canvas

[English](README.md) · 简体中文

在 Obsidian 的画布上手画家谱 —— 卡片、一代一行，**不需要为每个人准备一篇笔记**。

![Family Tree Canvas 画布](docs/screenshot.png)

## 为什么还要再做一个

目录里已有的族谱插件，基本都是从笔记反推关系：读属性或双链，再自动把图画出来。前提是每位亲戚都已经有笔记、字段齐全、写法一致；而且图只能表达这些字段装得下的东西。

这个插件的出发点反过来 —— 从一张空白画布开始。

| | 从笔记反推的插件 | Family Tree Canvas |
| --- | --- | --- |
| 关系存在哪 | 笔记属性、双链 | 插件自己的 `graph.json` |
| 每人必须有一篇笔记 | 必须 | **不必**，想挂才挂 |
| 卡片放哪 | 按数据算出来 | **你自己拖**，行自动对齐 |
| 上手成本 | 先搭一套属性规范 | 右键、打个名字，完事 |

- **不需要每个人都有笔记。** 一个人就是一张卡，有名字就够。生卒、性别、照片、笔记链接全是可选。不用建文件夹、不用写 frontmatter、不用编关系 ID。有笔记就挂上，只知道名字的长辈就只留名字 —— 你的库一点没被改。
- **图形化添加，点几下就成。** 右键卡片 → 添加子女／父亲／母亲／配偶／兄弟姐妹；右键空白处 → 添加人物，或者从人物库里挑一个。整套操作就这么多。
- **位置你说了算。** 横向随便拖，松手落进某一代。位置本身就是你定的数据，所以再婚、过继、跟爷爷奶奶长大的、只记得两代的分支，都摆得下 —— 不用迁就自动排版。
- **改完立刻看见。** 每次编辑当场重画，没有「生成」这一步，也没有两份数据要同步。

## 功能

- **一个人物库，多张布局。** 同样的人可以出现在「全家」「我这一户」「爷爷这一支」几张图里。每个人只存一份：在任一图里改名字或生卒日期，其它图跟着变。
- **吸附到行。** 卡片只横着拖；松手就落进某一代。紧缩时顺手把空行收干净。
- **紧缩空间并居中。** 走一遍整齐树算法：子女排到父母底下，整棵树收紧，父母落在子女正中间。点第二次结果不会再变。
- **夫妻换位。** 右键一键把夫妻左右对调，底下的子树跟着走。
- **关系能改。** 已经有父母的人还能再补一位；连错的亲子线、配偶线可以断开，连线会重画 —— 包括夫妻共用的那条子女下垂线。
- **亲戚计算器。** 选两个人，给出中文称呼 —— 公公、大姨子、堂侄女 —— 并把推算路径一路列出来。能算到 8 步以内的亲戚，选人时可以搜索。
- **主题。** 六个预设，也能全部自己调：男／女／未填的卡片底色、卡片文字色、已故者的填充与描边、亲子线和配偶线的颜色、线宽。悬停和选中的描边自动派生，浅色卡片上也看得清。
- **导出 Markdown。** 把一张布局写成能读的笔记：按代分节，写清婚姻和兄弟姐妹，给有笔记的人附上链接。
- **备份。** 一键写出带时间戳的 JSON，人物库和所有布局都在里面，存到你指定的文件夹。恢复时从列表里挑一份，动手前会先给当前状态另存一份保险。
- **英文和简体中文。** 在设置里切换，整个界面跟着变。

## 安装

上架之后，在**设置 → 第三方插件 → 浏览**里搜 **Family Tree Canvas** 即可。

在那之前只能手动装：

1. 从[最新的 release](https://github.com/zyk-13/family-tree-canvas/releases/latest) 下载 `main.js`、`manifest.json`、`styles.css`。
2. 三个文件放进 `<你的库>/.obsidian/plugins/family-tree-canvas/`。
3. 重启 Obsidian，在**设置 → 第三方插件**里启用 **Family Tree Canvas**。

## 用法

1. 命令面板里运行**打开家谱图**，或点左侧边栏的网络图标。
2. 右键空白处 → **添加人物**，打个名字就行，其它都可以空着。
3. 从卡片往外长：右键 → **添加子女／父亲／母亲／配偶／兄弟姐妹**。人物库里已有的人，用**从人物库添加**拉进来。
4. 摆位置靠拖。夫妻想换左右，右键 → **与「XX」互换左右**。
5. 排歪了就点**紧缩空间并居中**；后悔就点**撤销**。

## 数据存在哪

| 文件 | 内容 |
| --- | --- |
| `.obsidian/plugins/family-tree-canvas/graph.json` | 人物库和所有布局 |
| `.obsidian/plugins/family-tree-canvas/data.json` | 插件设置 |
| 你选的备份文件夹（默认 `family/家谱备份`） | 带时间戳的 JSON 备份 |

笔记只会被**引用**，插件从不新建、改名或改写你的笔记。

**卸载插件会把它的文件夹一起删掉，`graph.json` 也在里面。** 卸载前先导出一份备份 —— 工具栏上那个下载图标就是干这个的。

## 隐私

不联网、不上报、不需要账号。所有东西都留在你自己的库里，断网也能完整使用。

## 开发

```bash
npm install
npm run build   # 把 src/ 打包成 main.js
npm run dev     # 改动后自动重建
```

源码都在 `src/`：

| 文件 | 作用 |
| --- | --- |
| `src/main.js` | 插件入口：命令、备份恢复、设置页 |
| `src/view.js` | 画布视图：平移缩放、拖拽、吸附、工具栏 |
| `src/layout.js` | 布局计算、连线几何、整齐树紧缩 |
| `src/model.js` | 数据模型 v4、人物库、布局、持久化 |
| `src/modals.js` | 人物编辑、布局管理、亲戚计算、备份、主题等弹窗 |
| `src/kinship.js` | 关系路径搜索与中文称呼 |
| `src/theme.js` | 主题预设、派生色、CSS 变量输出 |
| `src/i18n.js` | 英文／中文字符串 |
| `src/backup.js` | 备份信封格式、解析、格式化 |
